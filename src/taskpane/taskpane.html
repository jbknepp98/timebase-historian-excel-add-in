Timebase Historian

This connects to the Historian's REST API directly from your browser. Enter the host and port only — not /api/help or any other path.

Authentication is handled by the server. It signs in to Pulse as client , so no client secret is entered or stored in Excel.

Saved on this computer for this add-in, not in the workbook. Better still, keep the secret out of Excel entirely: run node tools/set-credentials.js on the server and this section disappears. Use a client with read-only Historian access either way. See the security note.

Getting started

New to the add-in? Add the getting-started guide to this workbook: worked examples, a function reference, time expressions and troubleshooting as new sheets. Every example is a live formula you point at your own data on its Setup sheet.

Build a formula and insert it at the active cell.

Tags

One tag name per cell; blank cells are skipped. The formula references the range, so editing those cells changes the tags.

    Last value (step) writes one row per clock mark (07:00, 07:05, …) holding the last raw value at or before it, with no averaging. Use it for state and enum tags. Interval defaults to 5 minutes, quality to good, and values are cast to integers. A state that starts and ends between two rows (a one-second fault, say) will not appear: that is how snapshot sampling works.
